# Check if Autonomy Level is Set

Check if the autonomy level has been configured.

## Usage

``` r
autonomy_is_set()
```

## Value

*\[logical\]* TRUE if the autonomy level is set, FALSE otherwise.

## Examples

``` r
if (FALSE) { # \dontrun{
if (!autonomy_is_set()) {
  message("Autonomy level not configured")
}
} # }
```
